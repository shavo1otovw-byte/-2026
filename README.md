# САМАТ & КАНЫКЕЙ — тойго чакыруу

## Иштетүү

Node.js 20.19+ же 22.12+ орнотуп, долбоордун папкасында төмөнкүнү аткарыңыз:

```sh
npm install
```

`.env.example` файлын `.env` деп көчүрүп, `ADMIN_PASSWORD` үчүн өзүнчө күчтүү сырсөз коюңуз. `INVITED_GUESTS` маанисине чакырылгандардын жалпы санын жазыңыз. Андан кийин:

```sh
npm run dev
```

Чакыруу Vite көрсөткөн даректе ачылат (демейки боюнча `http://localhost:5173`), админ-панель `/admin` дарегинде. RSVP жооптору `data/wedding.sqlite` файлына сакталат.

Өндүрүштүк иштетүү үчүн `npm run build` жана `npm start` буйруктарын колдонуңуз. Өндүрүш чөйрөсүндө `.env` файлындагы администратор сырсөзүн жана HTTPSти сөзсүз конфигурациялаңыз.

## Админ-панель

`/admin` дарегине кирип, `.env` файлындагы сырсөздү жазыңыз. Бул баракка менюдан шилтеме берилбейт. Панелде RSVP жоопторун көрүп, өзгөртүп же өчүрүп, чакырылгандардын жалпы санын жаңырта аласыз. «Чакырылгандар» көрсөткүчүнүн баштапкы мааниси `INVITED_GUESTS` менен коюлат.
